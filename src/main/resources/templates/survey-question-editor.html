Primero añade una sección al borrador.

Una opción por línea: código | texto. Ejemplo: SI | Sí. El código identifica la opción; utiliza letras, números o guion bajo. Deja vacío para otros tipos.

Para tipos distintos de selección múltiple, deja mínimo 0 y máximo 1.

Condición de aparición

Opcional. La pregunta de control debe aparecer antes. Para quitar la condición deja vacíos ambos campos.

Por ejemplo SI. Si hay varios: SI|OTRO. Deben existir en la pregunta de control.
