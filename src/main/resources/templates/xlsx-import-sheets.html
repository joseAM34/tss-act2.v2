Elige la hoja con respuestas

El libro original está conservado. Escoge una hoja; cada hoja se revisa y confirma por separado. Todavía no se han incorporado respuestas.

La primera fila debe contener los encabezados. Las celdas vacías conservan su posición. Usa valores sin fórmulas ni celdas combinadas. Los números se leen como valores almacenados; no se aplican formatos de pantalla ni se convierten fechas numéricas de Excel. Para interpretar una fecha externa utiliza texto ISO 8601 con zona, o selecciona «No interpretar fecha externa».
